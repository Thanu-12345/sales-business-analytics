# Sales & Business Analytics Dashboard

A data analytics project that analyzes sales, profit, customer segments, products, regions, and payment methods using Python, SQL, and data visualization.

## 📊 Project Overview

This project demonstrates an end-to-end business analytics workflow:

- Data generation and preparation
- Exploratory Data Analysis (EDA)
- Business KPI analysis
- Sales and profitability analysis
- Customer segment analysis
- SQL-based business queries
- Data visualization
- Dashboard creation using Python

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- MySQL
- SQL
- Git & GitHub
